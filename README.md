# cadastro cliente

Projeto CRUD simples (cliente/cidade) feito em 2018 como parte de um teste técnico, usando Spring Boot 1.5.10 e Java 8.

> **Nota:** este é um projeto antigo, mantido aqui apenas como histórico. Não é atualizado ativamente e não reflete as práticas ou o stack que uso atualmente.

## Stack

- Spring Boot 1.5.10 / Java 8
- Spring Data JPA + MySQL
- Thymeleaf + Bootstrap 4

## Configuração local

O banco de dados é configurado via variáveis de ambiente (`src/main/resources/application.yml`):

- `DB_USER` (default: `root`)
- `DB_PASSWORD` (default: `changeme`)
